# 跳变沿 · 数字电子技术

《数字电子技术基础》自学课程的交互式网站：知识地图、课时计划、交互实验室、考点与诊断测试。

- 主线：输出由什么决定（组合 $Y=F(X)$ → 时序 $Q^*=F(X,Q)$）
- 知识地图：49 个课时的先修依赖关系（9 个模块）
- 课时计划：卡片 / 表格两种视图，筛选，进度记录（保存在浏览器本地）
- 交互实验室（9 个）：进制与编码、逻辑函数、卡诺图、138 / 151、触发器时序、任意进制计数器、序列检测器、555 定时器、AD / DA
- 知识树、最重要 15 点、最易错 15 点（翻卡）、考试题型与策略、能力成长路线、学习计划
- 基础水平诊断测试（不含答案，作答可一键复制）

纯静态页面，无需构建。本地预览：

```bash
python3 -m http.server 8766
```

说明：考试重要程度与题型占比为一般本科课程经验判断，不是任何学校的真实考点统计；学习时间为估计值。实验中的波形与结果均按器件逻辑实时计算。
